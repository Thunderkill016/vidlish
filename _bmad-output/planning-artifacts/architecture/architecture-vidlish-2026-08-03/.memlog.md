# Vidlish Architecture Memlog

- 2026-08-03 | event | Architecture run initialized in Fast Path for a build substrate consumed by BMAD, Codex, epics and stories; no presentation artifact requested.
- 2026-08-03 | constraint | Inherit final PRD, final UX, transcript acquisition research and SPEC-vidlish-lesson-engine without reopening product scope.
- 2026-08-03 | decision | Use a hexagonal modular monolith with a durable workflow pipeline; this binds all product modules and prevents UI, providers and database concerns from becoming one coupled layer.
- 2026-08-03 | decision | Use one TypeScript repository and one Next.js deployment for the web/API/workflow handlers; do not start with independently deployed microservices.
- 2026-08-03 | version | Next.js 16 App Router verified current and stable from official Next.js documentation.
- 2026-08-03 | version | Node.js 24 selected because it is LTS; Node.js 26 is Current rather than LTS as of this run.
- 2026-08-03 | version | TypeScript 6.0 selected as the conservative stable compiler line; TypeScript 7.0 is newly released and deferred until the Next.js/tooling ecosystem is proven for this codebase.
- 2026-08-03 | version | Zod 4 selected for runtime contracts and type inference.
- 2026-08-03 | version | Inngest TypeScript SDK v4 selected for durable multi-step workflows, checkpointing, retries, concurrency control and execution history.
- 2026-08-03 | version | Gemini model seed is stable `gemini-3.6-flash`, invoked through `@google/genai`; exact SDK package versions are lockfile-pinned at scaffold.
- 2026-08-03 | version | Supabase hosted Postgres/Auth/Storage selected; JavaScript client stays on the 2.x line and SSR helpers are lockfile-pinned because their API may evolve.
- 2026-08-03 | decision | Postgres is the system of record for user, job, transcript, lesson version and completion state; browser memory, function memory and Inngest state are not product truth.
- 2026-08-03 | decision | Only the generation workflow may advance `lesson_jobs.status/current_stage`; request handlers may create a job or submit user input but may not skip workflow transitions.
- 2026-08-03 | decision | Job creation is idempotent by owner + normalized video ID + CEFR + pipeline version within an active-job window; repeated requests return the existing job.
- 2026-08-03 | decision | Transcript acquisition is an ordered strategy registry behind a port, not a vendor-specific branch inside product code.
- 2026-08-03 | decision | Strategy classes cover existing captions, hosted transcript providers, Gemini URL/audio transcription, policy-gated unofficial extractors, user-approved tab audio, uploaded subtitle/audio and pasted transcript.
- 2026-08-03 | decision | `NO_CAPTIONS` is a strategy result, never a terminal product error while another permitted strategy remains.
- 2026-08-03 | decision | Unofficial extractors are disabled by default in public production and enabled only by an explicit environment feature flag after legal/policy review; private beta may use them behind the same port.
- 2026-08-03 | decision | Canonical transcript segments have stable IDs, millisecond offsets, normalized text, source type and optional confidence; downstream code consumes only this canonical contract.
- 2026-08-03 | decision | Browser tab audio is recorded in bounded chunks and uploaded to a private temporary bucket with signed URLs; chunks are deleted after transcription or failure and a scheduled sweeper enforces the TTL.
- 2026-08-03 | decision | Permanent video/audio storage is forbidden. Normalized transcript storage is owner-scoped and deleted when the dependent lesson is deleted, subject to final legal copy before public launch.
- 2026-08-03 | decision | Long videos have no hard duration rejection solely because of length. They are segmented by semantic/token/cost budgets; the engine may publish an overview plus micro-lesson candidates rather than silently truncating.
- 2026-08-03 | decision | Lesson generation follows the multi-stage Lesson Engine contract: preprocess → analyze → mine → plan → compose → deterministic validate → reviewer → targeted repair → publish.
- 2026-08-03 | decision | Gemini is an adapter and cannot mutate published lesson state directly; deterministic validators own schema, segment existence, source hydration, answerability and hard publish gates.
- 2026-08-03 | decision | Published lesson content is immutable and versioned. Regeneration creates a new `lesson_version`; mutable completion state is stored separately.
- 2026-08-03 | decision | Publishing a lesson version, updating the lesson pointer and completing the job happen atomically; partial lesson visibility is forbidden.
- 2026-08-03 | decision | Inngest execution is deduplicated and limited to one active run per job; event identity derives from job + pipeline version.
- 2026-08-03 | decision | `GenerationPolicy` is the only owner of quota, concurrency and estimated-cost acceptance; numeric values remain environment configuration.
- 2026-08-03 | decision | All provider keys remain server-only. Public browser configuration is limited to Supabase publishable values and non-secret feature flags.
- 2026-08-03 | decision | Supabase RLS is mandatory on every exposed owner-scoped table and private Storage bucket; application ownership checks are defense in depth, not a replacement for RLS.
- 2026-08-03 | decision | External inputs and model outputs cross a Zod boundary. Domain code never accepts raw provider response objects.
- 2026-08-03 | decision | User-facing errors use stable product codes with Vietnamese copy, retryability and safe action guidance; raw provider errors remain server-side.
- 2026-08-03 | decision | Every lesson version records transcript hash/source, pipeline/schema/prompt/model versions, provider request IDs, token/cost metadata and quality report.
- 2026-08-03 | decision | MVP job progress delivery uses persisted reads/polling. Realtime transport may be added later without changing job state ownership.
- 2026-08-03 | decision | Tests use provider fixtures by default. CI never calls live YouTube, transcript, STT or Gemini services.
- 2026-08-03 | decision | Pipeline/model changes must pass deterministic tests and regression evaluation on at least 10 representative videos across multiple CEFR levels.
- 2026-08-03 | decision | Environments are local, staging/private-beta and production; production data and secrets are never shared with preview/local environments.
- 2026-08-03 | assumption | Vercel hosts Next.js and the Inngest serve endpoint; Inngest Cloud coordinates durable execution; Supabase hosts Postgres/Auth/Storage.
- 2026-08-03 | assumption | Passwordless email OTP or magic link is the initial Supabase Auth method.
- 2026-08-03 | question | Exact paid transcript/STT provider and credentials are deferred until implementation/deployment; adapters and contracts are fixed now.
- 2026-08-03 | question | Monthly provider budget and account quotas are deferred until the owner supplies billing/API accounts.
- 2026-08-03 | question | Public-launch legal approval for transcript acquisition and retention remains a release gate, not an architecture blocker for private beta.

# BMAD-era project archive

This directory preserves project-specific artifacts created while Vidlish used BMAD.

It is **historical context, not active development authority**. Do not use sprint status, stories, readiness reports, PRDs, architecture notes, or generated plans here to override current product documents, `.specify/memory/constitution.md`, an active `specs/<feature>/` specification, or current code/tests.

The files below were moved from the former `_bmad-output/` tree during the 2026-08-22 Spec Kit migration. Their original contents are preserved so investigations can still recover prior decisions and rationale. Removed BMAD framework/config/skills remain available through Git history rather than as active repository tooling.
